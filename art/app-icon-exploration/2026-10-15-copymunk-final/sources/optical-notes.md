# 04 鼓腮小开心：macOS 小尺寸光学稿

两张源文件直接在 16×16、32×32 的目标坐标系里绘制；没有缩放 1024 SVG 的脸部路径。保留选中 04 的暖杏底、大圆亮眼、巨大奶油鼓腮、小圆浅耳、中央柔纵冠纹及开心开口笑。

| 项目 | 16px | 32px |
| --- | --- | --- |
| SVG | `macos-optical-16.svg` | `macos-optical-32.svg` |
| Xcode 文件槽位 | `icon_16x16.png` | `icon_16x16@2x.png`、`icon_32x32.png`，两槽共用同一 PNG |
| 底框 x / y | 1.568 | 3.136 |
| 底框宽 / 高 | 12.864 | 25.728 |
| 底框圆角半径 | 3.5792 | 7.1584 |
| 左 / 右眼中心 | (6.2, 8.1) / (9.8, 8.1) | (12.5, 16.4) / (19.5, 16.4) |
| 眼睛半径 x / y | 1.05 / 1.15 | 1.6 / 1.85 |
| 主高光 | 直径 1px 的圆 | 1.2×1.4px 椭圆 |
| 鼻子范围 | x 7.5–8.5，y 约 9.3–9.9 | x 15.2–16.8，y 约 18.65–19.7 |
| 嘴部范围 | x 7.2–8.8，y 10.55–11.85 | x 14.55–17.45，y 20.65–22.15 |

底框严格保留 `inset = 0.098 × 边长`、`radius = 0.2237 × 边长`，没有作外框像素吸附。底色保留 `#FFD7A5 → #F2AE78`。五官采用整数、半像素及少量更细的小数坐标，以面积覆盖控制轮廓与视觉重心；两眼、两耳、两腮的主体几何保持左右对称，高光保留母版的左上来光。

16px 将眼睛扩大、主高光扩大为 1px 直径，删除副高光、侧纹、模糊阴影和嘴内牙舌。开心嘴保留为小而向下收圆的开口，避免牙齿在不足一个像素的区域里把嘴抹淡。鼓腮以两块连续奶油轮廓为主，保留很淡的腮红；没有新增黑色外描边。

32px 另行布局，鼻子与嘴之间保留约 0.95px 的净空；扩大主高光，开心嘴采用 2.9×1.5px 的横向小开口，保留一颗奶白小门牙，删除细舌部。耳根外侧有很淡的短纹，不接近眼睛上沿或鼻梁。软体积用简化渐变表达，去除母版模糊阴影，底部仅留低不透明度的接地色。

渲染应从各自的目标 SVG 用 `resvg_py.svg_to_bytes` 渲染为目标边长的 8 倍，再用 Pillow `BOX` 面积平均降为目标大小；这只是对手工目标几何作抗锯齿，不经过 1024 主图。32px 导出一次，字节相同地用于两个 Xcode 槽位。

`optical-review.png` 显示原稿缩小结果、两份光学稿和 64px 原稿。每组上方是原尺寸，下方分别以 16×、8×、4× 最近邻整数放大，浅色及深色背景各一行。已做三轮渲染查看：第二轮扩大 16px 主高光、去掉细牙并加强小开心嘴；第三轮按独立 QA 将 32px 嘴改回更横向的小开口，避免纵向深点被读为 O 型嘴。64px 原稿的眼高光、鼻子和开心嘴可辨，故未新增 64px 光学稿。

16px 仍是极小的表情图标：牙齿、细侧纹与小副高光不作为该档的辨识条件；此档优先保留圆亮眼、鼓腮和开心表情，具体物种细节主要由较大尺寸承载。
